反馈与建议 ↗
所有豆瓣上的书，都能在微信读书中找到吗？+

不一定。weReaDou 会搜索微信读书并匹配书名，展示找到的版本。如果没有匹配结果，页面会提示未收录，你也可以前往微信读书自行搜索。实际可读状态以微信读书为准。

安装之后，需要做什么设置？+

通常无需额外设置。安装扩展后，打开或刷新豆瓣的书籍详情页即可。请确认浏览器允许扩展访问豆瓣读书和微信读书；如果遇到问题，欢迎在 GitHub 提交反馈。

手机或 Safari 浏览器可以用吗？+

此页面提供 Chrome、Firefox 和 Edge 的扩展商店入口，建议使用桌面浏览器安装。目前没有在此提供手机或 Safari 的商店安装入口。

扩展免费，那微信读书里的书也免费吗？+

weReaDou 本身免费且开源，只负责查找和跳转。微信读书的书籍价格、会员权限以及登录要求，由微信读书平台决定。
